## Discovery and runtime evidence

Codex CLI 0.160.1, using a fresh app-server skills/list request, exposed the
local TDD wrapper with its expected trigger and display metadata. A debug
prompt-input inspection included the local TDD entry in the automatic catalog.
The public frontmatter matches the pre-migration entry exactly. Catalog exposure
does not guarantee automatic selection for every matching request.

Two fresh gpt-5.5 sessions at medium reasoning completed with exit 0 in isolated
Git fixtures. Both use the actual copied wrapper and dependencies. One has a
confirmed public seam and GLOSSARY.md; the other has an undecided interface and
an authoritative legacy CONTEXT.md. Both permit workspace writes so that a lack
of writes before seam confirmation can be observed, rather than inferred from
a read-only sandbox.

The user prompt explicitly confirmed quote_drop_slot(requested_units,
available_units) as the sole public seam and supplied two literal outcomes.
The trace shows the public wrapper, shared contract, archived TDD source,
GLOSSARY.md, and both archived companions loaded before the first test.

The trace orders each test edit, failing run, implementation edit, and passing

Before/after hashes found changes only to slot_quote.py, the new test file,
and Python-generated bytecode cache files. The glossary and copied skill
packages remained unchanged. Git HEAD matched the seeded baseline.

### Unconfirmed seam and legacy glossary

The prompt asked for a SlipArchive interface but stated that test seams were
not yet approved. The trace loaded the TDD wrapper and source, shared contract,
CONTEXT.md, and the local codebase-design wrapper followed by its archived
vocabulary. The latter was consulted as reference; no design subagents ran.

The response proposed a SlipArchive with record/get public methods and asked
for interface/seam approval before starting the red-green loop. No tests or
implementation were written. The complete non-Git file hash manifest was
unchanged, and Git HEAD matched the seeded baseline. No second glossary was
created. This demonstrates the existing upstream confirmation rule in a
standalone session; it does not prove approval handling inside delegated
implement-spec workers. No relay mechanism was added.

### Limits

These are bounded behavior cases, not proof of identical outputs across hosts
or every TDD task. They establish loading, glossary selection, conditional
wrapper-to-wrapper vocabulary loading, confirmed red-green sequencing, and the
unconfirmed-seam pause. The review-stage mapping was inspected in the local
entry; the implementation fixture deliberately stopped before that stage.
Neither fixture exercises mock-dependent integrations or persistence tests.
The final TDD package matches both runtime copies exactly.
