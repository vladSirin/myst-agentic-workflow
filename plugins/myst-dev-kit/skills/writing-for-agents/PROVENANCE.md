# Writing-for-agents provenance

The complete method is from [Matt Pocock's skills](https://github.com/mattpocock/skills)
at the approved pin in [UPSTREAM.json](UPSTREAM.json). All three source files remain
byte-for-byte intact under references/upstream. Only SKILL.md maps to UPSTREAM.md
under ADR-0009. The former entry and companion already match the approved source;
there is no method delta. Previously omitted Codex metadata is included.

Myst owns the public entry, public metadata, source record, and this note.
The entry resolves the target document, project instructions, required copy
dependency, and workflow/publication authority through the shared contract.
Writing principles, progressive disclosure, completion criteria, pruning, and
skill-invocation guidance stay in the source. The original companion moved into
the complete source folder; it is not duplicated at the public root.
Model invocation remains enabled. For source-relative back-links, SKILL.md means
UPSTREAM.md in the source folder. Ordinary Markdown viewers do not apply that
filename mapping; the public entry states it for agents.
