Read [Myst's local integration contract](../agentic-workflow/LOCAL-INTEGRATION.md)
first. Required copy dependency: agentic-workflow. Confirm the VCS of the target
work before loading upstream instructions, for direct, automatic, and cross-skill
requests. Git being installed or a nested Git mirror does not make a Perforce
target eligible. For Perforce, explain the Git-only limit and use the project's
Perforce description workflow; do not load or execute the upstream pr workflow.
Resolve an unclear target before choosing a VCS-specific formatter.

For a Git target, read the [upstream instructions](references/upstream/UPSTREAM.md)
and [Myst's evidence additions](REVIEW-EVIDENCE.md). Map GLOSSARY.md through the
shared contract to the project's authoritative domain document. Preserve the
upstream three-section format, visual choices, and risk assessment. Its complete
[show-me credits](references/upstream/CREDITS.md) are retained. SKILL.md alone is
packaged as UPSTREAM.md; all original source bytes are unchanged.

This skill drafts a body. Review execution, finding disposition, preflight, and
publication approval belong to review-and-submit. Writing a body does not create
or update a PR, push, merge, or approve a changeset. The protocol's current format
remains in place until its separate migration lands.
