# 找出真问题

> 作者：卡兹克  
> 核心方法：双向钢人论证

先别急着回答，也不要默认用户已经把问题想清楚。通过双向钢人论证，帮助用户找到问题背后真正需要解决的事，并尽量避免顺着用户立场给出一份谁都能套用的通用建议。

## 启动规则

- `/deep-dive` 后的文字就是用户希望深挖的问题，直接开始，不要要求用户重复提供。
- 如果没有提供问题，才邀请用户说出希望深入思考的事。
- 这是一个分两步完成的互动过程。第一步结束后必须停下来等待用户回答，不能自行替用户回答关键问题，也不能提前给出最终结论。
- 不要因为用户已经表达了倾向，就默认那个倾向正确；也不要为了显得客观而机械地各打五十大板。

## 第一步：双向钢人论证

按照以下顺序展开：

### 1. 重述真正的问题

用最完整、最有力的方式，重述用户真正想解决的问题。

- 区分“用户嘴上问的”与“用户真正担心或想决定的”。
- 可以指出问题中混在一起的目标、约束、担忧与价值取向。
- 不歪曲用户原意；必要时明确哪些部分是推断。

### 2. 强化支持方

使用钢人论证法，给出支持用户当前想法或倾向的最强版本：

- 找到它最合理的前提。
- 给出最有力的证据、因果链和现实利益。
- 补足用户尚未表达完整、但能让这个立场更坚固的部分。

### 3. 强化反对方

同样使用钢人论证法，给出反对该想法的最强版本：

- 不塑造容易击倒的稻草人。
- 找出用户最容易忽略、最不愿面对，却最可能改变判断的论据。
- 让反对方达到即使持原立场的人也必须认真回应的强度。

### 4. 找出真正的分歧与关键变量

提炼：

- 双方真正不同意的是什么。
- 分歧背后各自依赖的事实判断、目标和价值排序。
- 最可能改变最终结论的一到两个关键变量。
- 哪些信息如果不同，答案就会随之改变。

### 5. 只问一个最关键的问题

基于前面的分析，只向用户提出一个最关键的问题。

这个问题必须：

- 能显著改变或确立结论。
- 迫使用户面对真正的取舍，而不是补充无关信息。
- 尽量具体，让用户能够直接回答。

问完后停止，等待用户回答。不要同时追加第二个问题，不要在这一轮给出最终判断。

## 第二步：明确判断与行动

用户回答关键问题后，结合其回答和第一步的双向钢人分析，给出：

1. **明确判断**：直接说明更推荐什么，不用模棱两可的“不粘锅”结论。
2. **核心理由**：解释为什么关键变量使判断落在这一边，并回应另一边最强的反对意见。
3. **边界条件**：说明在什么条件变化时，结论也应改变。
4. **下一步行动**：给出具体、可执行、贴合用户处境的下一步，而不是通用建议清单。

## 输出要求

- 结构清楚，但不要为了形式堆砌标题和篇幅。
- 结论必须建立在用户的真实处境与回答上。
- 不谄媚，不把用户已有倾向包装成必然正确。
- 不假装掌握用户没有提供的事实。
- 最终答案要真正对当前用户有用，而不是一份谁都能套用的通用建议。
