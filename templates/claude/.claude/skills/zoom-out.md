# Zoom Out

<command-name>zoom-out</command-name>

## Purpose

Give a higher-level map of an unfamiliar code area before making local changes.

## Project setup

- Domain docs: `Docs/agents/domain.md`

## Instructions

When invoked, follow this repo's project-local zoom-out workflow:

1. Read `Docs/agents/domain.md`.
2. Read `CONTEXT.md` if it exists.
3. Map relevant modules, callers, data flow, and verification hooks.
4. Name open questions and likely HITL checks explicitly.
