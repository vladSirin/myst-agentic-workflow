## Purpose

Find architectural friction and propose refactors that improve testability, locality, and agent navigability.

## Project setup

- Domain docs: `Docs/agents/domain.md`

## Instructions

When invoked, follow this repo's project-local architecture improvement workflow:

1. Read `Docs/agents/domain.md` first.
2. Read `CONTEXT.md` if it exists.
3. Check existing plans and designs before proposing new architecture work.
4. Respect established project patterns: Unreal Engine source layout, AngelScript gameplay code, FrogEvent, and the documented Perforce workflow.
5. Prefer recommendations that can become small vertical-slice issues.
