# Triage

<command-name>triage</command-name>

## Purpose

Move local markdown issues through the repo's status workflow.

## Project setup

- Issue tracker rules: `Docs/agents/issue-tracker.md`
- Status labels: `Docs/agents/triage-labels.md`
- Domain docs: `Docs/agents/domain.md`

## Instructions

When invoked, follow this repo's single `Status:` line triage model:

1. Read the issue file and any linked PRD or plan.
2. Read `Docs/agents/triage-labels.md` for the allowed statuses and lane rules.
3. Start any generated triage comment with:

   ```markdown
   > *This was generated by AI during triage.*
   ```

4. Update only the issue's `Status:` line and append comments under `## Comments`.
5. Use `closed` directly for agent-verifiable work only after all required checks pass.
6. Use `resolved` when implementation is done but human verification is still required.
