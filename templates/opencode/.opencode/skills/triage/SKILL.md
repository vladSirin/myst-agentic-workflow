# Triage

Read the issue file, linked PRD or plan, and `Docs/agents/triage-labels.md`.

Update only the issue's `Status:` line and append any generated comments under `## Comments`. Start generated triage comments with:

```markdown
> *This was generated by AI during triage.*
```

Use `closed` directly for agent-verifiable work only after all required checks pass. Use `resolved` when implementation is done but human verification remains.
