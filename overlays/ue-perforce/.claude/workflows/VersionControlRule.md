# CRITICAL WORKFLOW REQUIREMENT

## Mandatory Versioning Step

After modifying, adding, or deleting files, you **MUST**:

1. **FIRST**: Make sure they are checked out or added to source control.
2. **ONLY THEN**: Present the changelist status to the user in the next response as an info section.

---

## Zero Exceptions

This applies to **EVERY USER REQUEST** involving file changes, regardless of:

- Complexity (simple or complex)
- Tool type (file operations, searches, web requests, etc.)
- User urgency or apparent simplicity
- Whether you previously got approval in this conversation

---

## Enforcement

> [!CAUTION]
> If you do not follow this requirement, you have violated this requirement.
> This is a **mandatory step** and cannot be skipped.

---

## Workflow Summary

**For each user request:** `Checkout → Present Changes`
